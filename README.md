# 消防安全公共知识 · 刷题

基于 5 份《消防安全公共知识考试》模拟卷（卷A~E）的本地刷题小程序。**单文件交付**：双击 `index.html` 即用，发给朋友只需传这一个文件。

## ✨ v0.2 特性

### 功能
- **210 题题库**：卷A~E × 42题（填空10 + 选择20 + 判断10 + 简答2），数据内嵌单文件
- **四种题型全支持**：
  - 选择题：点击选项即判分，错误标红/正确标绿并显示正确答案
  - 判断题：点 √ / × 判分
  - 填空题：手动输入，**严格匹配**判分（trim 后完全一致，如 "10" ≠ "10%"）
  - 简答题：查看参考答案折叠区 + **自评模式**（可随时改判，当前选择高亮）
- **多模式刷题**：按卷筛选 / 按题型筛选 / 🎲 随机洗牌 / 📕 错题重刷 / ⭐ 收藏夹
- **收藏功能**：题目卡左上角 ☆ 收藏本题；工具栏"收藏夹"只刷收藏题
- **清除记录**：一键清空答题统计与错题本（**收藏保留**），发朋友前可先清理
- **答题记录 upsert**：改答案后可重新提交，统计/错题本自动保持一致（答对→答错进错题本，答错→答对移除）
- **进度持久化**：localStorage 保存已刷/答对/正确率/错题本/收藏，刷新不丢
- **响应式设计**：桌面宽屏 + 手机窄屏自适应（工具栏自动换行、无横向溢出）

### 视觉
- **Anthropic 设计语言**：暖米白底（#F5F1EA）+ 深棕黑字 + 陶土红强调（消防红降饱和），英文衬线标题混排
- **毛玻璃材质**：题目卡半透明磨砂（blur 26px），背景色块透出模糊；工具栏/统计/导航液态玻璃
- **消防场景背景**：内联 SVG 插画——消防员持水枪喷水浇火焰、灭火器待命、消防栓、水珠点缀（低透明度不抢内容）
- **Apple 动效**：弹簧反馈（按压缩放）、切题卡片浮现动画、下拉展开弹性形变；`prefers-reduced-motion` 自动降级
- **自研液态玻璃下拉**：替代原生 select，弹出面板也是玻璃质感 + 弹性动画

## 📁 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 交付产物（单文件，数据+样式+脚本+背景SVG 全内嵌，双击即用） |
| `questions.json` | 210 题结构化数据（可单独维护） |
| `parse_docs.py` | 从含答案 docx 解析题目 → questions.json |
| `build_html.py` | 构建 index.html（数据 + 前端代码合并） |

## 🔧 重新构建

```bash
# 更新题库后重建：
python parse_docs.py   # 从 卷X_含答案.docx 重新解析
python build_html.py   # 生成新 index.html
```
